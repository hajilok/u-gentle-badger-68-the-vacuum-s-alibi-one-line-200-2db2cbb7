# The Vacuum's Alibi: One Line, 200 Characters

Entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7?ref=41fw6r6c) on [make.fun](https://make.fun/r/41fw6r6c).

## Usage

Runs on Node 22+ (`program/v1`) and deterministically writes the single-line UTF-8 entry (`<= 200` characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set locally):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
